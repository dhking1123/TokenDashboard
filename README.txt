Codex Usage Dashboard — Windows x64

CodexUsageDashboard.exe를 실행하세요. Python 설치는 필요하지 않습니다.
v4: 일반 모드의 WEEK 또는 5H 게이지를 더블클릭하면 해당 항목의 사용량/잔여량 표시가 전환됩니다.
USED는 왼쪽부터 사용량을, LEFT는 오른쪽부터 잔여량을 채웁니다. 각 항목의 선택은 저장됩니다.
잔여 100%는 체크, 전부 소진은 자물쇠로 표시합니다. 경고 색상은 실제 사용량 기준입니다.
v5: 미니멀 모드에서도 WEEK/5H 영역 더블클릭으로 사용량/잔여량을 전환합니다.
일반 모드와 선택 상태를 공유합니다. USED는 왼쪽부터, LEFT는 오른쪽부터 채웁니다.
v3: 화이트 모드의 퍼센트 및 100% 자물쇠에 1px 짙은 녹색 테두리를 추가했습니다.
노란색/빨간색 경고 색상과 다크 모드 디자인은 그대로 유지됩니다.
v2: 상단 5H 토글 추가. 기본은 WEEK만 표시합니다.
일반 모드는 5H 글자와 토글, 미니멀 모드는 토글만 표시합니다.
켜면 5시간 영역만큼 창이 아래로 늘어나고, 끄면 원래 높이로 줄어듭니다.
오른쪽 상단 위치와 너비는 유지하며, 표시 선택은 다음 실행에도 저장됩니다.
5시간 데이터가 Codex 본 한도인지 Spark 한도인지 해당 영역의 이름으로 구분합니다.
실행하는 PC에 Codex가 설치되어 있고 본인 계정으로 로그인되어 있어야 합니다.
이 EXE에는 제작자의 계정 정보, 인증 토큰, 사용 기록이 포함되어 있지 않습니다.

주간 사용량은 계정에서 제공하는 데이터로 표시합니다.
로그인되지 않았거나 조회가 실패하면 --로 표시하며 30초마다 다시 조회합니다.
계정/설치 버전에서 제공하지 않는 항목은 표시되지 않을 수 있습니다.
TOKENS는 조회 API가 반환한 누적값이며 남은 구독 토큰 수가 아닙니다.

상단 화살표: 일반/미니멀 전환 (오른쪽 상단 위치 유지)
상단 -: 최소화 / X: 종료
하단 원형 화살표: 새로고침 / 해 모양: 다크·화이트 전환
테마 설정 저장 위치: %LOCALAPPDATA%\CodexUsageDashboard\settings.json

코드 서명되지 않은 개인 제작 앱이므로 Windows에서 경고가 나타날 수 있습니다.
신뢰할 수 있는 경로로 전달받은 파일인지 확인하세요.
