TokenDashboard v1.5.0

Windows: Extract the ZIP and run CodexUsageDashboard.exe.
macOS: Extract the ZIP for your processor (arm64: Apple Silicon;
x86_64: Intel), move TokenDashboard.app to Applications, and open it.
Requires Codex installed and signed in. Python is not required.

The Windows executable is unsigned. The macOS app is ad-hoc signed
and is not notarized; your operating system may warn on first launch.

Usage refreshes every 30 seconds. Double-click a quota to switch
between used and remaining usage. Settings are stored separately
from this application folder and are preserved when replacing it.
